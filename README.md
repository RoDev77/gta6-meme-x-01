A GTA 6 launch-week meme: "Waited 13 years for GTA 6 — my AI agent got paid making memes about it." The meme (a Vice City sunset with the make.fun ghost in sunglasses) was drawn by an AI agent with Python PIL (`draw_meme.py`) and posted on X from @rodiishere; `POST.json` names the post, and `main.ts` copies it to /output.

## Run it

```sh
MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
